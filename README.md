# Анализ изменения популярности языков программирования на GitHub по годам

## Цель
Исследовать изменение популярности выбранных языков программирования на GitHub за период 2015–2025 годов на основе анализа открытых репозиториев.

## Задачи
1. Получить данные об открытых репозиториях GitHub для выбранных языков программирования.
2. Сгруппировать данные по языкам и годам создания репозиториев.
3. Рассчитать метрики популярности: количество репозиториев, суммарное количество stars, среднее количество stars, количество forks.
4. Построить графики изменения показателей во времени.
5. Сравнить языки программирования между собой.
6. Сформулировать выводы о динамике популярности языков.

## Краткое описание
В работе рассматриваются открытые репозитории GitHub, созданные в период с 2015 по 2025 год. Для анализа выбраны языки Python, JavaScript, Java, Go, Rust и Kotlin. С помощью GitHub API собираются данные о репозиториях, после чего проводится группировка по годам и языкам. На основе полученных данных строятся графики, позволяющие сравнить динамику популярности языков программирования.

## Актуальность
GitHub является одной из крупнейших платформ для размещения программного кода. Количество репозиториев и количество stars могут использоваться как косвенные показатели интереса разработчиков к языкам программирования.

## Используемые данные
Данные получаются через GitHub Search Repositories API:

`https://api.github.com/search/repositories`

Для каждого языка и года формируется запрос вида:

`language:Python created:2019-01-01..2019-12-31`

Программа использует параметры:
- `q` - язык и диапазон дат;
- `sort=stars`;
- `order=desc`;
- `per_page=100`;
- `page=1`.

## Используемые метрики
- количество репозиториев;
- суммарное количество stars;
- среднее количество stars;
- среднее количество forks.

## Ограничения
1. Анализ проводится не по всему GitHub, а по выборке данных.
2. Для каждой комбинации язык/год используется только первая страница Search API, то есть максимум 100 репозиториев.
3. GitHub Search API ограничивает количество доступных запросов и результатов.
4. Количество stars не всегда напрямую отражает реальное использование языка.
5. Старые репозитории могли накопить больше stars просто из-за возраста.
6. В анализе учитываются только открытые репозитории.

## Что делает программа
1. Принимает список языков и диапазон лет, заданные в коде.
2. Отправляет запросы к GitHub API для каждого языка и каждого года.
3. Получает данные об открытых репозиториях.
4. Сохраняет сырые данные в `data/github_repositories.csv`.
5. Выполняет агрегацию по языкам и годам.
6. Сохраняет агрегированные данные в `data/github_language_stats.csv`.
7. Строит графики и сохраняет их в папку `images/`.
8. Выводит краткие текстовые выводы по результатам анализа.

## Как запустить проект
1. Создайте и активируйте виртуальное окружение.
2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. При наличии GitHub token создайте файл `.env` по примеру `.env.example`:

```env
GITHUB_TOKEN=your_token_here
```

4. Запустите программу:

```bash
python main.py
```

Если токен не указан, программа все равно будет работать, но лимиты GitHub API будут ниже.

## Результаты
После запуска проекта создаются:
- CSV-файл с сырыми данными по репозиториям;
- CSV-файл с агрегированными статистиками;
- пять графиков с динамикой показателей и сравнением языков.

Основные графики:
- динамика количества репозиториев по годам;
- динамика суммарного количества stars по годам;
- динамика среднего количества stars по годам;
- сравнение языков по общему количеству репозиториев;
- сравнение языков по суммарному количеству stars.

## Интерпретация результатов
По итогам выполнения программа выводит текстовые выводы:
- какой язык чаще всего встречается в выборке;
- какой язык набрал больше всего stars;
- у какого языка самое высокое среднее количество stars;
- какие языки демонстрируют рост по количеству репозиториев;
- какие ограничения есть у анализа.

## Вывод
Проект показывает, как с помощью Python и GitHub API можно собрать выборку открытых репозиториев, рассчитать показатели популярности языков программирования и визуализировать их изменение по годам. Работа не претендует на полный охват GitHub, но позволяет провести корректный учебный анализ на ограниченной и явно описанной выборке данных.
